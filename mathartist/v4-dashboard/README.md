# MathArtist V4 Human Aesthetic Dashboard

Open `index.html` directly in a browser.

This is a working interaction prototype, not a replacement for the real MathArtist generators.

Core interaction:
- single click = mark/unmark POTENTIAL
- double click = inspect fullscreen
- select one or more stepping stones
- choose MICRO / SMALL / MEDIUM / WILD mutation pressure
- branch
- selected parents survive unchanged
- undo / new root / shuffle
- delayed retrospective response

Production integration should wire this UI to the real V4 `OPEN_BLIND` and `HUMAN_OPEN_ENDED` APIs.
