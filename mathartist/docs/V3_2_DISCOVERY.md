# V3.2 — Dumb discovery at volume

V3.2 makes the search loop intentionally less intelligent.

`seed program P + admitted controls theta -> P(theta) -> minimal observer -> morphology descriptors`

The machine is allowed to remove only technical failures. It does not optimize beauty, valence, rasa, attention, or semantic labels in OPEN.

## Two independent loops

### MACHINE / OPEN
1. draw roots and local mutants at high volume;
2. execute the exact frozen seed;
3. reject only technical failures;
4. compute morphology coordinates;
5. retain coverage/novelty stepping stones;
6. estimate seed fertility from the diversity of valid descendants.

### HUMAN / POTENTIAL
A human can mark a specimen POTENTIAL. That signal is stored separately and may seed an explicit human-directed branch, but never changes OPEN ranking. This is the intended creative division of labor: the machine explores blindly; the human notices possibility.

## Fertility, not beauty

A seed is fertile when local parameter changes reach many distinct morphology regions. V3.2 uses image-derived structural coordinates only as a coverage proxy. No claim is made that these coordinates measure beauty.

## Corpus rule

The #つぶやきProcessing ecosystem is treated as a seed laboratory. Metadata and attribution can be indexed; third-party code is not vendored unless its license/permission allows it. The target is to identify mathematically fertile seeds and mechanisms, not imitate a visual style.
