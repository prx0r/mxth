# MathArtist V3 — control surfaces, not renderers

## Thesis

MathArtist is a discovery instrument for parameter spaces already latent in mathematics and science.

`source -> admitted control surface -> dumb search -> minimal observation -> response/archive`

The source family is immutable. V3 does **not** ask an LLM to beautify equations and does not synthesize new equations in the main evolutionary loop. It asks a narrower question: **what lives in the legitimate control space of this result?**

A native source exposes `M(theta)`, where every component of `theta` has evidence and a claim scope. Search is deliberately stupid: random roots, local mutation, occasional crossover, stepping-stone retention.

## Three scopes

1. `same-family`: changes a parameter/initial condition/branch explicitly admitted by the mathematical or scientific family.
2. `observation-only`: sampling/viewing control; never counted as scientific variation.
3. `numerical-only`: solver/resolution control; used for convergence and robustness, not phenotype novelty claims.

Equation/operator synthesis is outside V3's default mode.

## Minimal observer principle

Prefer the source's native output. Points become points, trajectories become thin lines, scalar states use a fixed monotone grayscale mapping, structures use atoms/bonds or native geometry. The observer must not rescue an uninteresting mathematical state with effects.

## Human-response modulation

The archive has separate selection/readout channels rather than one beauty score:

- OPEN: novelty, branch fertility, coverage; no taste target.
- ATTENTION: 5s, 10|5, 20|10, replay.
- VALENCE: signed pleasant/unpleasant report, kept separate from attention.
- ABSORPTION: self-reported absorption.
- RASA: retrospective response labels inspired by classical rasa categories; never treated as a direct measurement of Abhinavagupta's theory.
- QRI-HYPOTHESIS: structural descriptors (symmetry, spectral organization, recurrence, compressibility) are predictors/coordinates, not definitions of valence.

This permits separate lineages: e.g. `OPEN`, `HIGH-ABSORPTION`, `POSITIVE-VALENCE`, `ADBHUTA`, `SHANTA`, `REPLAY`. A phenotype can be unpleasant yet highly absorbing; V3 preserves that distinction.

## Discovery / confirmation firewall

Adaptive search is discovery. Any relationship found between controls/structure and human response must be frozen as a hypothesis and tested on fresh parameter samples and fresh viewers before confirmatory language is used.
