# V3 domain adapters

The universal interface is not a universal equation language. It is a control surface.

## Frontier mathematics / formal proofs

A proof assistant or paper agent is useful upstream to establish identity and admissibility. Axiom's AXLE is an example of infrastructure that can verify and manipulate Lean proofs; this is a provenance/verification input, not an aesthetic engine.

Adapter job:
1. fingerprint theorem/proof/code;
2. identify executable construction, if any;
3. extract parameters/branches/initial data explicitly admitted by it;
4. attach source evidence to every control;
5. freeze the surface;
6. search controls with ordinary stochastic code.

A theorem with no executable family and no meaningful control surface is allowed to contribute **nothing**. V3 must not force every theorem into pictures.

## Developmental bioelectricity / Michael Levin ecosystem

This domain is almost ideal for V3 because computational models already expose meaningful experimental controls. BETSE models ion channels, gap junctions, concentrations, voltages, currents, GRNs and reaction networks through configuration. Published computational work also explicitly sweeps parameters such as gap-junction conductance and channel/morphogen terms.

Search examples, only where admitted by a specific model:
- gap-junction coupling;
- channel conductance/expression;
- initial Vmem pattern;
- field feedback strength;
- morphogen generation/decay;
- lesion/perturbation geometry;
- simulation time.

Outputs remain native: Vmem state, currents, concentrations, tissue geometry, gene state. Here the archive can ask a second scientific question alongside aesthetics: which control regions are robust, multistable, regenerative, or unexpectedly pattern-forming?

## AlphaFold / structural biology

Do **not** mutate trained model weights and call the result biology. Treat the released inference system as immutable. Search legitimate inputs and sampling controls that correspond to a defined experiment: sequence variants, ligand/ion composition, covalent modifications, model seeds/samples, and other documented inference inputs. Preserve confidence outputs beside every structure.

The visual observer should be minimal molecular geometry. Interesting lineages can be selected by structural novelty/uncertainty as well as human response, but an attractive predicted structure is not evidence of biological function.

## Why these domains fit one system

`M(theta)` can be a theorem construction, a PDE solution family, a tissue simulator, an artificial-life system, or a structure-prediction pipeline. MathArtist only needs an evidenced `theta`, reproducible execution, native outputs, and honest claim scope.
