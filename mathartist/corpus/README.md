# V3.2 seed corpus

V3.2 treats compact mathematical programs as seeds, not styles. The corpus registry stores attribution/provenance and acquisition metadata; it does not vendor third-party sketch code unless licensing/permission permits it.

Pipeline: exact seed program -> expose admitted numeric controls -> high-volume blind sweep -> technical integrity -> morphology coverage/fertility -> human POTENTIAL validation.

Primary discovery sources:
- #つぶやきProcessing portal: https://tweetprocessing.projectroom.jp/
- attribution-forward runnable archive: https://tsubuyaki.art/
- Hau_kun historical roundups: https://haukun.projectroom.jp/
- NEORT pchj03 curated picks: https://medium.com/neort/pchj03-challenge-picks-526dccf4c19a

The registry is intentionally metadata-first. Importing code must retain artist, original post, exact source, and license/permission status.
